# AD688 — Career Evaluation Product (Group 1)

Career evaluation product for job seekers targeting **Business Intelligence / Data Analyst** roles in **U.S. depository banking (NAICS 5221)**.

**Live site:** https://fuadbbv.github.io/ad688-career-evaluation-group1/

## Structure

- `index.qmd` — project scope and product question
- `introduction.qmd` — problem, rationale, literature review
- `data/` — `raw` (not committed), `interim`, `processed`
- `figures/`, `outputs/` — generated charts and tables
- `references.bib`, `csl/` — bibliography and citation style
- `notebooks/` — analysis notebooks

## Setup

1. Copy `.env.example` to `.env` and add your MET API key. Never commit `.env`.
2. Render the site: `quarto render`
