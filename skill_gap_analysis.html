Skill Gap Analysis

Purpose

A market-wide list of in-demand skills is not informative until it is compared against an existing sample person or persons. This analysis performs that comparison by measuring what employers in NAICS 523 ask for against records of what each member of the project team can actually do, and reports the distance between the two.

Method

Demand is identified from 7,074 job postings, all of which list skills. The comparison skills come from an internal self-assessment: each team member rated their own proficiency on nine skill areas, on a five-point scale from beginner to expert. These rankings were then checked against those nine areas from the postings to determine which frequently requested skills fall outside them.

The gap for a given skill is the difference between the level the market requires and the level the individual holds. The required level was identified by how often the skill appears in postings.

Market Demand for Each Skill Area

The team searched SKILLS_NAME, the full skill list, rather than SOFTWARE_SKILLS_NAME to allow a more standard comparison as two of the selected areas- Communication and Financial Domain Knowledge- are not software and appear only in the full skills list. The other seven areas are software-related, and the full list is more complete than the software-only list.

PANEL_PATH = Path("data/processed/career_market_panel.csv")
SKILL_FIELD = "SKILLS_NAME"

# Each skill area pattens 

AREA_PATTERNS = {
    "Python":                    r"\bpython\b",
    "SQL":                       r"\bsql\b|mysql|postgresql",
    "Machine Learning":          r"machine learning|deep learning|predictive model|scikit|tensorflow|pytorch",
    "Cloud Computing":           r"cloud|\bazure\b|snowflake|databricks",
    "Communication":             r"communication|presentation|public speaking|storytelling",
    "AWS":                       r"\baws\b|amazon web services|amazon redshift|amazon s3",
    "Dashboard/Reporting":       r"dashboard|\breporting\b|tableau|power bi|looker|qlik|business intelligence|data visuali",
    "Git":                       r"\bgit\b|github|gitlab|version control",
    "Financial Domain Knowledge": r"financ|investment|securities|portfolio|accounting|asset management|risk management|trading|fixed income|derivative|valuation",
}
assert set(AREA_PATTERNS) == set(df_skills.columns), "Area names must match the ratings table"

panel = pd.read_csv(PANEL_PATH, usecols=[SKILL_FIELD], dtype=str)
n_postings = len(panel)

def clean_skill(name):
    return re.sub(r"\s*\([^)]*\)", "", name).strip().casefold()

skills_per_posting = (
    panel[SKILL_FIELD].fillna("").str.split(";")
    .apply(lambda items: {clean_skill(x) for x in items if x.strip()})
)

# Match each distinct skill name once, then map postings to areas
skill_freq = Counter(s for skills in skills_per_posting for s in skills)
skill_to_areas = {
    s: {a for a, p in AREA_PATTERNS.items() if re.search(p, s)} for s in skill_freq
}
areas_per_posting = skills_per_posting.apply(
    lambda skills: set().union(*(skill_to_areas[s] for s in skills))
)

demand = pd.DataFrame({
    "Postings": {a: int(areas_per_posting.apply(lambda x: a in x).sum()) for a in AREA_PATTERNS}
})
demand["Share"] = demand["Postings"] / n_postings * 100
demand = demand.sort_values("Share", ascending=False)

Gap Analysis

Market share is converted into a target proficiency. The cut-offs are based on team assumptions. Because an area counts a posting if any of its skills is listed, broad areas would score higher shares than narrow ones, and the targets should be read with that in mind.

5–15% 2
under 5% 1 
target = pd.cut(
    demand["Share"], bins=[-0.1, 5, 15, 30, 50, 100], labels=[1, 2, 3, 4, 5]
).astype(int)

order = list(demand.index)                     # 

#most to least demanded
df_skills = df_skills[order]
gap = (target - df_skills).clip(lower=0)

Learning Order

Below is a table of team member learning priorities for each area, where each member’s priority is determined by their gap weighted by the area’s market share.

priority = gap.mul(demand["Share"] / 100, axis=1)

rows = []
for member, scores in priority.iterrows():
    top3 = scores[scores > 0].sort_values(ascending=False).head(3)
    rows.append({
        "Member": member,
        "Learning order (levels to gain)": " → ".join(
            f"{s} (+{gap.loc[member, s]})" for s in top3.index
        ) or "Meets every target",
    })
pd.DataFrame(rows).set_index("Member")

Machine Learning and Cloud Computing are also areas where the team can improve to meet market demand. The above learning order table provides a clear roadmap for each member to prioritize their skill development based on market demand and their current proficiency levels.

How to Close the Skill Gap

The way the team can close the gaps is a combination of peer learning and external courses. The following are some suggestions to start the improvement process:

External resources can be utilized such as Coursera learning paths, Udemycourses, and other online resources to fill in the gaps. The team can also consider pairing sessions where members with higher proficiency in certain areas can mentor others. For example, Katie can run short pairing sessions for Fuad and Jonathan in Python, SQL, and Machine Learning. Jonathan’s financial domain knowledge can support the others in interpreting finance-specific postings. For areas like Cloud Computing or AWS, the team can pick one shared course and use the course EC2 work as practice.
